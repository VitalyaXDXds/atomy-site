# Сайт Лилии Гуцеловой — Atomy

Все файлы лежат в одной папке, без вложенных папок. Загружайте их в репозиторий все вместе.

Перед публикацией впишите свои контакты:
- в конце `index.html` строка `var WA="79XXXXXXXXX", TG="your_telegram_username";`
- в файле `config.js` те же две переменные (для блога, каталога и помощника)

Каталог товаров редактируется в `products.js`.
